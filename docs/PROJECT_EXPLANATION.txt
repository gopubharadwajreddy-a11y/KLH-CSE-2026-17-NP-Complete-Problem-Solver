ALGOMASTER - FINAL PROJECT

Purpose: one Java toolkit for selecting and testing advanced algorithmic strategies.

Integrated coverage:
CO1 - problem strategy advisor for substring search, alignment, flow, matching, NP-hard optimization, randomized and parallel tasks.
CO2 - KMP, Z Algorithm, Rabin-Karp rolling hash.
CO3 - Edit Distance, Matrix Chain, Interval DP (Burst Balloons), Bitmask DP (TSP), Subset DP (Equal Partition).
CO4 - Edmonds-Karp, Dinic, Bipartite Matching, max-flow modeling.
CO5 - 2-approximation Vertex Cover, Greedy Set Cover, scheduling strategy discussion.
CO6 - Randomized QuickSort (Las Vegas), Monte Carlo Pi, Prefix Sum and Reduce with work/span discussion.

The application is presented as one integrated project rather than separate CO demonstrations.
