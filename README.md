## Abstract

The **NP-Complete Problem Solver** is an interactive software toolkit developed to demonstrate advanced algorithmic techniques for solving and analyzing complex computational problems. The system focuses on classical **NP-complete and NP-hard problems**, including **Vertex Cover, Set Cover, Traveling Salesman Problem (TSP), and Bin Packing**, using both exact and approximation approaches. Users can provide different input sizes and observe the generated solutions, execution time, solution quality, and approximation ratios. The project applies concepts from **Dynamic Programming, Graph Algorithms, Approximation Algorithms, Complexity Theory, and Randomised Algorithms**, as covered in the DSA syllabus. Graphical performance reports are generated to compare algorithms and study their scalability as input size increases. The toolkit provides a practical learning environment for understanding the trade-off between computational efficiency and solution accuracy in advanced algorithm design.
