ALGOMASTER - ADVANCED ALGORITHM TOOLKIT
========================================
Core Java project integrating all six course outcomes without CO-wise labels.

Modules:
1. Problem Strategy Advisor
2. String Matching
3. Dynamic Programming
4. Network Flow & Matching
5. Optimization & Approximation
6. Randomized & Parallel Algorithms
7. Dataset Lab
8. Algorithm Guide

Run in VS Code terminal from the project root:
  javac src/AlgoMaster.java
  java -cp src AlgoMaster

JDK 17+ recommended.
